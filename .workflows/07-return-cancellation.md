# Cancel the return leg

The driver cannot cover the return and cancels that leg.

1. Open the return leg from **Driver → Upcoming** and tap **Cancel return leg**.
2. Review the affected pickup and refund. Confirm the cancellation with an **$80 refund** in the example.
3. The rider sees the return marked **Cancelled** and a refund record. The outbound leg and original receipt remain available.

**Demo behavior.** The refund equals the approved return fare and is simulated. The driver can cancel the return before or after the outbound ride takes place.
